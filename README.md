# Backend – Chatbot-Driven Smart Planner

## Overview

This backend powers a **chatbot-driven smart planning system** built for **AI in Consumer Experiences**.  
It converts natural language conversations into **structured, personalized plans** for campus life and short travel by balancing **time, cost, accessibility, and user preferences**.

The backend acts as the **core intelligence layer**, while the frontend handles only user interaction and visualization.

---

## Responsibilities

- Process chat messages from the frontend
- Integrate with a chatbot API for:
  - Intent detection
  - Follow-up suggestion generation
- Extract structured constraints from user input
- Maintain per-session state
- Generate and refine plans using custom logic
- Return structured JSON for live plan visualization

---

## Tech Stack

- Node.js
- Express.js
- Chatbot API (for conversational intelligence)
- In-memory session storage
